# 💻 開発環境学習クイズ

開発環境を整える過程で学んだ技術知識を、4択クイズで楽しく復習できるゲームです。

## 📋 特徴

- **シンプルなUI**: 直感的で使いやすいデザイン
- **4択形式**: 各問題に4つの選択肢から選べます
- **即座フィードバック**: 回答後に正解/不正解と解説が表示されます
- **進捗表示**: プログレスバーで進捗状況が確認できます
- **スコア表示**: 最終スコアと評価メッセージが表示されます
- **ランダム出題**: 問題順と選択肢順が、開始時と再挑戦時に毎回変わります

## 🎮 使い方

1. リポジトリをクローンまたはダウンロード
2. `index.html` をWebブラウザで開く
3. 各問題に対して4つの選択肢から最適なものを選択
4. 「次へ」ボタンをクリックして次の問題へ進む
5. すべての問題に回答後、スコアが表示されます
6. 「もう一度挑戦」ボタンでリスタート

## 🔧 クイズの追加・編集

`quiz-data.json` を編集することで、新しいクイズを追加できます。

### JSON形式:

```json
{
  "quizzes": [
    {
      "question": "問題文",
      "options": [
        "選択肢1",
        "選択肢2",
        "選択肢3",
        "選択肢4"
      ],
      "answer": 0,
      "explanation": "解説（オプション）"
    }
  ]
}
```

- `question`: 問題文
- `options`: 4つの選択肢を配列で指定
- `answer`: 正解のインデックス（0〜3）
- `explanation`: 解説テキスト（任意）

## 🎨 カスタマイズ

`index.html` の `<style>` セクションでCSSを編集することで、色やフォントなどをカスタマイズできます。

## 📊 評価基準

- 100%: 完璧です！🎉
- 80%以上: よくできました！👍
- 60%以上: まあまあですね
- 60%未満: 頑張りましょう！📚

## 🚀 ローカルでの実行

```bash
# シンプルなHTTPサーバーを起動（Python 3）
python -m http.server 8000

# または Node.js を使う場合
npx http-server
```

その後、ブラウザで `http://localhost:8000` にアクセス
